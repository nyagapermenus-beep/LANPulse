# LANPulse demo guide

1. Open the published GitHub Pages URL.
2. Review the device totals, online/offline state and average latency.
3. Open **Devices** to search, filter or add a sample device.
4. Open a device detail panel to review its sample status and configured ports.
5. Use **Run checks** to generate simulated check results and demonstrate alerts.
6. Open **Topology** to review parent-child relationships.
7. Open **Alerts & events** to acknowledge sample alerts.
8. Open **Reports** and export a CSV.

When presenting, state clearly that this GitHub Pages edition uses synthetic data. It is a frontend demonstration, not a live network probe.
