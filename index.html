About this report

Interpretation and data coverage

The current dashboard is showing demonstration data. Availability and latency values are illustrative and must not be treated as measurements of a production network. Switch to Live mode to collect measurements from authorised devices.

About LANPulse

Network monitoring for small and medium enterprise environments.

LANPulse EnterpriseVersion 1.0.0 · MVP

LANPulse provides a central dashboard for checking reachability, service availability and response times of explicitly registered network devices. It includes a standalone demonstration mode and an optional Python/Flask backend for live monitoring.
